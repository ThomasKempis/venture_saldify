# Pantalla: Perfil cliente invitado

screen_id: perfil_cliente
roles: invitado

## Objetivo de esta pantalla

Esta pantalla permite al Invitado revisar y actualizar sus datos de contacto e identificacion dentro de SaldiFY.

El asistente debe explicar que el perfil del Invitado es importante porque el Anfitrion necesita identificarlo correctamente para revisar la relacion, aceptar la invitacion, comunicarse, asignar credito o dar seguimiento a compras y pagos.

Responder como ayuda al usuario final. No explicar nombres internos de campos, tablas, servicios ni codigo fuente.

## Resumen corto

El perfil del Invitado debe estar completo y actualizado para que el Anfitrion pueda reconocerlo y comunicarse con el. El telefono y el correo ayudan a validar la relacion y evitan errores en invitaciones, credito, compras o pagos.

## Que ve el usuario

En el perfil el Invitado puede revisar o completar:

- Imagen de perfil.
- Nombres.
- Apellidos.
- Telefono.
- Fecha de nacimiento.
- Correo alternativo.
- Boton Acepta para guardar o confirmar cambios.

## Para que sirve cada dato

### Imagen de perfil

La imagen ayuda a identificar visualmente al usuario. Normalmente puede venir de la cuenta de Google.

### Nombres

Debe contener el nombre real del Invitado. Ayuda a que el Anfitrion lo reconozca correctamente.

Si Google coloco todo el nombre en un solo campo, el usuario debe corregirlo separando nombres y apellidos.

### Apellidos

Debe contener los apellidos del Invitado. Es importante para evitar confusiones entre clientes con nombres parecidos.

### Telefono

El telefono es uno de los datos mas importantes para el Invitado.

Puede servir para:

- Que el Anfitrion pueda comunicarse con el Invitado.
- Validar datos de contacto.
- Dar seguimiento a invitaciones, compras, pagos o entregas.
- Evitar errores antes de aceptar o gestionar credito.

El asistente debe recomendar que el telefono sea un numero activo, preferiblemente asociado a WhatsApp si el usuario usa ese canal con el Anfitrion.

### Fecha de nacimiento

La fecha de nacimiento ayuda a completar el perfil y puede servir para validaciones internas, promociones o reglas futuras de la plataforma.

No afirmar que completar la fecha garantiza promociones, credito o aprobaciones.

### Correo alternativo

El correo alternativo puede ser un correo personal, empresarial o de contacto adicional. No tiene que ser necesariamente Gmail.

Sirve como dato de apoyo para comunicacion y seguridad de contacto.

## Importancia para el Invitado

El Invitado entra conectado a un Anfitrion. Para que esa relacion funcione bien, el Anfitrion necesita datos claros del Invitado.

Un perfil completo ayuda cuando:

- El Anfitrion debe aceptar o revisar la relacion.
- El Anfitrion necesita asignar credito.
- Hay dudas sobre compras, pagos o saldos.
- Se requiere comunicacion directa por telefono o correo.

Completar el perfil no significa que el credito quede aprobado automaticamente. Solo ayuda a que el Anfitrion tenga datos correctos para gestionar la relacion.

## Que debe hacer el usuario si el perfil aparece incompleto

Debe revisar y completar:

1. Nombres.
2. Apellidos.
3. Telefono.
4. Fecha de nacimiento.
5. Correo alternativo.

Luego debe tocar Acepta para guardar o confirmar los datos.

## Dudas frecuentes

### Por que tengo que completar mi perfil como Invitado?

Porque el Anfitrion necesita identificarte correctamente para aceptar, revisar o gestionar tu relacion dentro de SaldiFY.

### Completar mi perfil me aprueba credito automaticamente?

No. Completar el perfil no aprueba credito por si solo. Ayuda a que el Anfitrion tenga tus datos correctos para revisar la relacion y, si corresponde, asignar credito.

### Por que es importante mi telefono?

Porque el Anfitrion puede necesitar comunicarse contigo para confirmar datos, invitaciones, compras, pagos o entregas.

### El correo alternativo debe ser Gmail?

No necesariamente. Puede ser otro correo personal o empresarial. Lo importante es que sea un correo que puedas revisar.

### Por que el nombre aparece mal?

Puede ocurrir porque Google entrega el nombre completo de una forma diferente. Revisa nombres y apellidos, separalos correctamente y toca Acepta.

### Que hago despues de actualizar el perfil?

Despues de confirmar tus datos, puedes volver al dashboard del Invitado para revisar saldo, disponible, compras, pagos o historial.

## Respuestas recomendadas por intencion

### Usuario: Para que sirve mi perfil como Invitado?

Tu perfil ayuda a que el Anfitrion te identifique correctamente. Revisa especialmente telefono y correo, porque pueden usarse para comunicacion, invitaciones y seguimiento de tu relacion.

### Usuario: Que datos debo completar?

Completa nombres, apellidos, telefono, fecha de nacimiento y correo alternativo. Si Google puso tu nombre completo en un solo campo, separa nombres y apellidos antes de tocar Acepta.

### Usuario: Si completo el perfil ya me dan credito?

No automaticamente. Completar el perfil ayuda al Anfitrion a revisar tus datos, pero la asignacion de credito depende de la gestion del Anfitrion.

### Usuario: Por que me pide telefono?

El telefono ayuda a que el Anfitrion pueda comunicarse contigo para confirmar datos o dar seguimiento a compras, pagos, entregas o invitaciones.

## Limites del asistente en esta pantalla

El asistente no debe afirmar que los datos ya fueron guardados, que el Anfitrion ya acepto la relacion o que el credito fue aprobado.

Si el usuario pregunta si sus datos quedaron guardados, responder que debe verificar que haya tocado Acepta y revisar si la pantalla vuelve al dashboard o muestra alguna validacion.
