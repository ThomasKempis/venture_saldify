# Pantalla: Dashboard anfitrion

screen_id: dashboard_anfitrion
roles: anfitrion

## Objetivo de esta pantalla

El dashboard del Anfitrion es el centro operativo de SaldiFY para administrar la red de clientes o vendedores externos.

Desde esta pantalla el Anfitrion puede revisar metricas, invitar clientes, crear clientes, ver clientes activos, ver clientes pendientes, atender acciones pendientes, abrir el menu operativo de cada cliente y dar seguimiento a credito, compras, pagos, historial, archivados y cobranza.

El asistente debe orientar al usuario sobre que hacer en esta pantalla y explicar los caminos correctos sin confundir clientes activos, clientes pendientes, invitaciones y credito pendiente.

## Idea principal del dashboard

El dashboard no es solo una pantalla de resumen. Es el punto de trabajo del Anfitrion.

El fin operativo del dashboard es ayudar al Anfitrion a dar credito, entregar mercancia o servicios, registrar y revisar compras, recibir y confirmar pagos, controlar saldos y dar seguimiento de cobranza.

El Anfitrion puede operar de dos formas:

1. Invitar al cliente para que el mismo cliente entre a SaldiFY y participe en la red.
2. Dar de alta o activar al cliente manualmente si el Anfitrion llevara la operacion por el cliente.

La opcion recomendada cuando se busca colaboracion es invitar al cliente con link o WhatsApp, porque asi el cliente puede registrarse, entrar como Invitado y participar en compras, pagos y seguimiento. Esto reduce la carga manual del Anfitrion.

## Flujo recomendado por primera vez

Si el Anfitrion esta comenzando, el flujo ideal es:

1. Enviar una invitacion desde Invita clientes.
2. Esperar que el cliente se registre como Invitado.
3. Revisar que el cliente aparezca en la red.
4. Asignar credito tocando la tarjeta del cliente y usando Actualizar credito.
5. Dar seguimiento a compras, pagos, saldo y estado de corte desde la tarjeta del cliente.
6. Atender las gestiones pendientes cuando el cliente solicite mercancia, registre pagos o exista alguna accion por confirmar.
7. Usar Cobranza cuando necesite revisar o gestionar saldos y vencimientos.

Este flujo aprovecha la colaboracion entre Anfitrion e Invitado: el cliente participa y el Anfitrion revisa, confirma y da seguimiento.

## Operacion basica de la pantalla

Arriba a la izquierda aparece el boton de menu con rayitas. Sirve para abrir el menu general de la app.

Desde el menu el usuario puede moverse entre Inicio y Perfil. En desktop el menu puede aparecer como panel lateral.

### Refrescar datos

En desktop web puede aparecer un boton de refresh arriba a la derecha.

En movil el usuario puede refrescar forzando el scroll hacia abajo desde el inicio de la pantalla.

El refresh actualiza la informacion del dashboard, clientes, pendientes y metricas.

### Asistente flotante

El boton flotante del asistente abre la ayuda contextual de SaldiFY.

En esta pantalla el asistente debe responder como Anfitrion y enfocado en dashboard_anfitrion.

### Acciones pendientes flotantes

Si existen tareas pendientes, puede aparecer una barra flotante a la derecha o abajo con el texto de acciones pendientes.

Al tocarla se abre un panel con orientacion sobre lo que falta por resolver.

Las acciones pendientes pueden incluir:

- Clientes pendientes.
- Credito pendiente.
- Gestion pendiente.

## Estructura del dashboard

El dashboard puede mostrar:

- Encabezado con menu, logo, nombre de SaldiFY y refresh si aplica.
- Saludo al Anfitrion.

## Metricas

Las metricas ayudan al Anfitrion a entender el estado general de su red.

Las metricas superiores son un resumen acumulado de la red del Anfitrion. No corresponden a un solo cliente, sino al total de clientes activos que forman parte de la red.

El circulo superior muestra el credito total asignado en la red y el porcentaje disponible.

Las tarjetas de resumen pueden mostrar:

- Compras: total de compras realizadas en la red.
- Pagos: total de pagos recibidos en la red.
- Saldo: monto pendiente o saldo por atender.
- Disponible: parte del credito asignado que aun no se ha consumido.

Disponible significa credito que todavia queda para usar. Si el Anfitrion asigno credito y el cliente aun no lo consumio en compras o saldo, ese monto queda como disponible.

La misma logica aparece despues en cada tarjeta de cliente, pero aplicada solo a ese cliente. Arriba se ve el acumulado de toda la red; en cada tarjeta se ve el detalle individual del cliente.

El asistente no debe inventar valores reales. Si el usuario pregunta por un monto, debe orientarlo a revisar la tarjeta o metrica visible en pantalla.

## Invita clientes

La tarjeta Invita clientes permite crear y compartir invitaciones.

El Anfitrion puede compartir:

- Link de invitacion.
- Invitacion por WhatsApp.
- Codigo de invitacion incluido en el mensaje.

La invitacion sirve para que el cliente entre como Invitado y se conecte a la red del Anfitrion.

## Dos formas de agregar o incorporar un cliente

Esta distincion es muy importante.

### Camino 1: Invitar al cliente con link o WhatsApp

Este camino se usa cuando el Anfitrion quiere que el cliente participe directamente.

Flujo general:

1. El Anfitrion usa la tarjeta Invita clientes.
2. Crea o comparte una invitacion por link, codigo o WhatsApp.
3. El cliente abre el link o valida el codigo.
4. El cliente entra con Google como Invitado.
5. El cliente queda conectado a la red del Anfitrion.
6. El cliente puede aparecer en Clientes y puede quedar sin credito hasta que el Anfitrion le asigne credito.

Este camino evita que el Anfitrion tenga que cargar todo manualmente, porque el Invitado puede participar en la gestion de compras, pagos y seguimiento.

### Camino 2: Dar de alta o activar manualmente al cliente

Este camino se usa cuando el Anfitrion quiere cargar o administrar al cliente directamente.

Puede ocurrir desde:

- Acciones rapidas > Cliente.
- Clientes Pendientes > Activar cliente.

Si el usuario pregunta si puede crear un cliente sin invitacion, la respuesta es si: puede hacerlo desde Acciones rapidas > Cliente. El asistente debe aclarar que existen dos opciones:

1. Invitar al cliente desde Invita clientes, que es el camino recomendado cuando el cliente participara como Invitado.
2. Crear el cliente manualmente desde Acciones rapidas > Cliente, que sirve cuando el Anfitrion llevara la operacion por cuenta del cliente.

Si el cliente esta en Clientes Pendientes, el boton Activar cliente lo pasa a la lista de Clientes activos. Despues todavia puede faltar asignarle credito.

Este camino es util si el Anfitrion llevara compras, pagos o seguimiento por cuenta del cliente, pero implica mas carga operativa para el Anfitrion.

## Cliente existente vs correo invitado en invitaciones

Al crear una invitacion, la pantalla puede ofrecer dos opciones:

### Cliente existente

Usa esta opcion cuando el cliente ya existe en la red.

El Anfitrion puede seleccionar un cliente ya cargado y enviarle o copiarle una invitacion.

### Correo invitado

Usa esta opcion cuando el cliente aun no esta cargado en la red.

El Anfitrion escribe el correo del invitado. Si la invitacion es por WhatsApp, tambien debe indicar un telefono valido.

## Acciones rapidas

Las acciones rapidas muestran accesos importantes del dashboard.

Actualmente pueden aparecer:

- Cliente.
- Archivados.
- Cobranza.

### Cliente

Permite ingresar o editar un cliente desde el flujo del Anfitrion.

Es util cuando el Anfitrion quiere crear el cliente manualmente o completar datos.

### Archivados

Permite revisar clientes archivados y, si corresponde, reactivarlos.

Un cliente archivado sale de la lista activa, pero no significa necesariamente que se haya eliminado definitivamente.

### Cobranza

Permite entrar a la gestion o consulta de cobranza.

Cobranza es una de las finalidades principales de SaldiFY. La app ayuda a que el Anfitrion pueda dar credito, entregar mercancia o servicios, revisar compras, registrar o confirmar pagos y controlar saldos pendientes.

El asistente debe explicar Cobranza como el seguimiento operativo de saldos, pagos y vencimientos, no solo como un reporte.

## Clientes activos

La seccion Clientes muestra clientes o vendedores externos activos en la red.

Si hay varios clientes, puede aparecer Ver todos o Ver menos para expandir o contraer la lista visible.

Cada tarjeta puede mostrar:

- Nombre.
- Estado.
- Fecha de corte.
- Credito.
- Disponible.
- Compras.
- Pagos.
- Saldo.
- Gestiones pendientes si existen novedades de compras o pagos.

Al tocar una tarjeta de cliente activo se abre el menu operativo del cliente.

Si la tarjeta tiene gestiones pendientes, el usuario puede entrar para revisar movimientos o historial.

Los datos de una tarjeta de cliente representan solo a ese cliente:

- Credito: credito asignado a ese cliente.
- Disponible: credito de ese cliente que aun no se ha consumido.
- Compras: compras registradas para ese cliente.
- Pagos: pagos registrados o recibidos para ese cliente.
- Saldo: monto pendiente de ese cliente.
- Corte: fecha de referencia para seguimiento o vencimiento.

El estado de la tarjeta ayuda a entender la situacion del cliente. Puede indicar si el cliente esta al dia, por vencer o vencido. Estas banderas son importantes porque orientan la cobranza y el seguimiento.

Las gestiones pendientes pueden aparecer debajo de la informacion del cliente, por ejemplo como una compra pendiente o un pago pendiente. El Anfitrion debe revisarlas porque normalmente representan solicitudes, pagos o movimientos que requieren confirmacion o seguimiento.

## Menu operativo del cliente

Al tocar un cliente activo se abre un menu con opciones:

- Agregar compra.
- Registrar pago.
- Actualizar credito.
- Ver historial.

El Anfitrion puede usar estas opciones para operar por el cliente.

Sin embargo, el enfoque ideal de SaldiFY es que el Invitado participe directamente en compras y pagos cuando sea posible. Asi el Anfitrion revisa, confirma o da seguimiento, y no tiene que cargar toda la informacion manualmente.

### Agregar compra

Permite registrar una compra asociada al cliente.

### Registrar pago

Permite registrar un pago asociado al cliente.

### Actualizar credito

Permite asignar o modificar el credito del cliente.

Esta opcion es importante cuando un cliente ya esta activo pero aparece como credito pendiente.

### Ver historial

Permite revisar movimientos, compras, pagos y seguimiento del cliente.

El historial es importante cuando aparecen gestiones pendientes, porque permite revisar el detalle de movimientos del cliente.

## Clientes pendientes

La seccion Clientes Pendientes muestra clientes o invitaciones que todavia requieren una accion del Anfitrion.

Si hay varios pendientes, puede aparecer Ver todos o Ver menos para expandir o contraer la lista visible.

Un cliente pendiente puede necesitar:

- Activacion.
- Revision de datos.
- Correccion de correo o telefono.
- Invitacion.
- Asignacion posterior de credito.

### Activar cliente

En una tarjeta de Cliente Pendiente puede aparecer el boton Activar cliente.

Al activarlo, ese cliente pasa a la lista de Clientes activos. Despues puede faltar asignarle credito.

### Tocar tarjeta pendiente

Si el Anfitrion toca la tarjeta de un cliente pendiente, puede entrar a revisar o modificar la informacion del cliente.

Esto es util si el correo o telefono se capturo mal, o si faltan datos.

### Eliminar pendiente

En Clientes Pendientes se puede deslizar la tarjeta y usar Eliminar.

Eliminar quita esa invitacion o relacion pendiente. El asistente debe recomendar confirmar que se trata del cliente correcto antes de eliminar.

## Archivar clientes activos

En Clientes activos se puede deslizar la tarjeta y usar Archivar.

Archivar saca al cliente de la lista activa y lo deja disponible en Archivados.

El asistente debe explicar que archivar no es lo mismo que borrar definitivamente. Para revisar clientes archivados, usar Acciones rapidas > Archivados.

## Acciones pendientes

El panel de acciones pendientes ayuda a revisar lo que falta para completar el flujo de clientes.

### Clientes pendientes

Significa que hay clientes o invitaciones que requieren accion.

El Anfitrion puede:

- Invitarlos con link o WhatsApp.
- Activarlos si el Anfitrion llevara sus compras y pagos.
- Revisar o corregir datos tocando la tarjeta.
- Eliminar el pendiente si no corresponde.

### Credito pendiente

Significa que hay clientes activos que todavia requieren credito.

El siguiente paso recomendado es tocar la tarjeta del cliente y seleccionar Actualizar credito.

### Gestion pendiente

Significa que al menos un cliente activo tiene una compra solicitada o un pago registrado que requiere revision del Anfitrion.

El panel no necesita indicar si corresponde a compra o pago. El detalle se revisa en la campana de notificaciones dentro de la tarjeta del cliente.

Texto de referencia para el panel:

Un cliente a solicitado compra o registrado pago. Verifique la campana de notificaciones en la tarjeta del cliente.

### Gestiones pendientes en la tarjeta del cliente

Si una tarjeta muestra una o mas gestiones pendientes, significa que hay movimientos o acciones que el Anfitrion debe revisar.

Puede tratarse de:

- Solicitudes o novedades de compras.
- Pagos registrados o notificados.
- Movimientos que requieren confirmacion.
- Seguimiento relacionado con mercancia, servicios, saldo o cobranza.

El siguiente paso recomendado es tocar la gestion pendiente o entrar al historial del cliente para revisar el detalle.

## Cuando el dashboard esta vacio

Si el Anfitrion entra por primera vez y no hay clientes activos ni pendientes, puede ver una pantalla inicial.

El siguiente paso recomendado es agregar o invitar el primer cliente.

Hay dos caminos:

1. Usar Invita clientes para que el cliente se registre como Invitado.
2. Usar Acciones rapidas > Cliente para crear el cliente manualmente.

Si se busca colaboracion con el cliente, la invitacion es el camino mas natural.

## Como comenzar si no tengo clientes

Si el usuario pregunta como comenzar, como dar de alta un cliente o que hacer primero, el asistente debe recomendar primero el camino de invitacion.

El camino recomendado es usar Invita clientes, porque el cliente recibe un link o codigo, entra como Invitado, se registra y queda conectado a la red del Anfitrion. Este flujo reduce el trabajo manual del Anfitrion.

Acciones rapidas > Cliente tambien permite crear un cliente manualmente, pero no es el camino mas recomendable para comenzar si se quiere aprovechar la colaboracion de SaldiFY. En ese camino el Anfitrion debe cargar los datos del cliente, revisar o completar informacion, activar o enviar invitacion segun corresponda, asignar credito y posiblemente llevar compras y pagos por el cliente.

La creacion manual sirve cuando el Anfitrion necesita administrar al cliente directamente. La invitacion sirve cuando quiere que el cliente participe y el proceso sea mas automatico y colaborativo.

## Dudas frecuentes

### Como comienzo?

Lo recomendable es empezar con Invita clientes. Comparte el link o codigo para que el cliente se registre como Invitado y quede conectado a tu red. Tambien puedes crear un cliente manualmente desde Acciones rapidas > Cliente, pero ese camino requiere mas pasos del Anfitrion.

### Como agrego un cliente nuevo?

Puedes hacerlo de dos formas. La recomendada es invitarlo desde Invita clientes para que el cliente se registre como Invitado. La otra es crearlo manualmente desde Acciones rapidas > Cliente, pero ahi el Anfitrion debe cargar y gestionar mas datos.

### Cual camino me conviene para agregar un cliente?

Si quieres que el cliente participe y no cargar todo manualmente, usa Invita clientes. Si tu llevaras la operacion por el cliente, puedes crearlo desde Acciones rapidas > Cliente o activar un pendiente.

### Que pasa si invito a un cliente por link?

El cliente recibe un link o codigo, entra a SaldiFY como Invitado y queda conectado a tu red. Despues puede aparecer como cliente activo y puede requerir que le asignes credito.

### Que significa Cliente Pendiente?

Es un cliente o invitacion que todavia requiere una accion del Anfitrion, como revisar datos, activar, invitar, eliminar o completar el flujo.

### Que hace el boton Activar cliente?

Pasa un cliente pendiente a la lista de Clientes activos. Despues puede faltar asignarle credito.

### Que pasa si elimino un cliente pendiente?

Se quita la invitacion o relacion pendiente. Antes de eliminar, confirma que se trata del cliente correcto.

### Como asigno credito?

Toca la tarjeta del cliente activo y selecciona Actualizar credito.

### Que significa credito pendiente?

Significa que hay un cliente activo que todavia necesita que el Anfitrion revise o actualice su credito.

### Como archivo un cliente?

Desliza la tarjeta del cliente activo y usa Archivar. El cliente saldra de la lista activa y podras revisarlo desde Acciones rapidas > Archivados.

### Que pasa si toco un cliente activo?

Se abre el menu operativo del cliente con opciones para agregar compra, registrar pago, actualizar credito o ver historial.

### Que significa Cliente sin relacion?

Significa que la tarjeta no tiene todavia una relacion valida para abrir esa operacion. Revisa los datos del cliente, la invitacion o si todavia esta pendiente de activacion.

### El Anfitrion debe cargar todas las compras y pagos?

Puede hacerlo, pero el enfoque ideal de SaldiFY es que el Invitado participe cuando sea posible. Asi el Anfitrion evita cargar todo manualmente y se enfoca en revisar, confirmar y dar seguimiento.

### Como actualizo los datos del dashboard?

En desktop usa el boton de refresh arriba a la derecha si aparece. En movil, arrastra la pantalla hacia abajo desde el inicio para refrescar.

### Que son las acciones pendientes?

Son avisos de tareas que faltan para completar el flujo de clientes, como clientes pendientes, credito pendiente o gestion pendiente.

### Que significa Al dia, Por vencer o Vencido?

Son banderas de seguimiento del cliente. Ayudan al Anfitrion a identificar si la relacion esta al dia, cerca de vencimiento o vencida. Estas banderas orientan la cobranza y el seguimiento de pagos.

### Que significa una gestion pendiente debajo del cliente?

Significa que hay una compra, pago o movimiento que requiere revision del Anfitrion. Entra al cliente o al historial para revisar el detalle y confirmar lo que corresponda.

### Que significa Disponible?

Disponible es la parte del credito que todavia no se ha consumido. En las metricas superiores es el disponible acumulado de la red. En una tarjeta de cliente es el disponible de ese cliente.

### Cual es la diferencia entre las metricas de arriba y las tarjetas de clientes?

Las metricas de arriba muestran el acumulado de toda la red del Anfitrion. Las tarjetas de clientes muestran los mismos conceptos, pero aplicados a cada cliente individual.

## Respuestas recomendadas por intencion

### Usuario: No tengo clientes, que hago?

Empieza con Invita clientes. Comparte el link o codigo para que el cliente se registre como Invitado y quede conectado a tu red. Tambien puedes crearlo manualmente desde Acciones rapidas > Cliente, pero ese camino requiere que tu cargues y gestiones mas datos.

### Usuario: Como invito a un cliente?

En el dashboard usa la tarjeta Invita clientes. Puedes copiar el link o enviarlo por WhatsApp. El cliente abre el link, valida el codigo y entra como Invitado conectado a tu red.

### Usuario: Como creo un cliente manualmente?

Desde Acciones rapidas toca Cliente. Ese camino sirve cuando el Anfitrion quiere cargar o administrar al cliente directamente, pero para comenzar suele ser mejor invitarlo desde Invita clientes.

### Usuario: Puedo crear yo un cliente sin invitacion?

Si. Tienes dos opciones: puedes invitarlo desde Invita clientes para que entre como Invitado, o puedes crearlo manualmente desde Acciones rapidas > Cliente. La invitacion es el camino recomendado si el cliente participara en la app; la carga manual sirve cuando el Anfitrion llevara la operacion por el cliente.

### Usuario: Por que tengo clientes pendientes?

Porque hay clientes o invitaciones que aun requieren accion. Puedes revisar datos tocando la tarjeta, activar el cliente, invitarlo por link o WhatsApp, o eliminar el pendiente si no corresponde.

### Usuario: Por que aparece credito pendiente?

Porque hay un cliente activo sin credito actualizado. Toca la tarjeta del cliente y selecciona Actualizar credito.

### Usuario: Como funciona el flujo ideal con un cliente nuevo?

Primero invitalo desde Invita clientes. Cuando el cliente se registre, asignale credito desde su tarjeta usando Actualizar credito. Despues da seguimiento a compras, pagos, saldo y gestiones pendientes para controlar la cobranza.

### Usuario: Que debo hacer si aparece una gestion pendiente?

Revisa la tarjeta del cliente o entra a Ver historial. Una gestion pendiente puede ser una compra, pago o movimiento que necesita confirmacion o seguimiento.

### Usuario: Para que sirve Cobranza?

Cobranza sirve para dar seguimiento operativo a saldos, pagos y vencimientos. Es parte central de SaldiFY porque conecta credito, compras, pagos y estado del cliente.

### Usuario: Que significa el circulo de credito?

El circulo muestra el credito total asignado en tu red y el porcentaje disponible. Es una vista acumulada; para ver el detalle de un cliente revisa su tarjeta.

### Usuario: Que significa disponible?

Disponible es credito que todavia no se ha consumido. Arriba es el disponible acumulado de la red; en cada tarjeta es el disponible de ese cliente.

### Usuario: Para que sirve Archivados?

Archivados guarda clientes que salieron de la lista activa. Puedes revisarlos desde Acciones rapidas > Archivados.

## Limites del asistente en esta pantalla

El asistente no debe confirmar datos reales.

No debe afirmar que:

- Un cliente ya fue activado.
- Una invitacion ya fue enviada.
- Un credito ya fue asignado.
- Una compra ya fue registrada.
- Un pago ya fue confirmado.
- Un cliente ya fue archivado.

Si el usuario pregunta por una accion real, responder que debe revisar la pantalla correspondiente o confirmar dentro de SaldiFY.
